# Windows Capture — minimal dialog

Layout like the reference QuickCapture dialog, but NOT its dark theme.
This app keeps its own light theme: warm paper background #FDF8F0,
dark ink text #1F2937, one teal accent #0F766E.

Size: about 640 x 208.

- Window bar: "Quick Capture" on the left, minimise / maximise / close
  on the right.
- Heading: "Quick Capture", with the hint on the right:
  "Enter save · Shift+Enter newline · Esc dismiss".
- One input row: white box, "capture a thought…", with a teal
  "➤ Add" button on the right.
- Below: a small "+" button for files or tags, with
  "Notion connected" status on the right.
- Tags and files are reached via "+", so the dialog stays minimal.
  Tags remain multi-select when opened.
- Saves locally first, then to Notion. Status is always visible.
